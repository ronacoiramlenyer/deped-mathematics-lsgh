                                              FUNDAMENTALS OF DATA ANALYTICS
                                                          Pre-requisite: None

Course Description:
This course introduces foundational principles and practices in data analytics, while developing essential 21st-century skills. Learners
enhance their information, visual, media, technology, and digital literacy through data collection, cleaning, processing, visualization,
storytelling, and the responsible use of digital tools. The course also fosters creativity, critical thinking, problem solving, teamwork,
collaboration, and communication skills in performing data analytics for informed decision making in data-driven fields. Throughout the
course, learners gradually develop a project that applies data analytics concepts to solve real-world problems using datasets prepared for
presentation by the end of the course.
Elective: Academic
Time Allotment: 80 hours for one term

Performance Standards

  •   The learners can illustrate data life cycle and uphold data privacy and ethical principles. They process data accurately and
      securely by creating backups, cleaning datasets to address missing or inconsistent entries, converting data formats based on
      specified requirements, and using spreadsheet tools such as filters and pivot tables to refine datasets and generate meaningful
      insights for decision-making.
  •   The learners can perform statistical analyses, apply conditional and lookup functions, create visualizations using spreadsheets
      and data visualization software, communicate insights through data storytelling, and design and present a complete data
      analytics project using real-world data.
